### **分页查询项目接口**

#### **1. 基本信息**

- **接口名称**：项目查询
- **请求方式**：`POST`
- **请求路径**：`/settleProjectLook/search.do`
- **请求头**：`Content-Type: application/json`
- **返回格式**：`JSON`

---

#### **2. 请求参数（Request Body）**

**参数格式**：`JSON`

```json
{
  "current": "当前页码",
  "size": "每页条数",
  "name": "项目名称（模糊匹配）",
  "deptId": 27, // 部门ID（默认27）
  "projectManagerName": "项目经理姓名（模糊匹配）",
  "projectSaleName": "项目销售姓名（模糊匹配）",
  "startDate": "开始日期（可选，格式：yyyy-MM-dd）",
  "endDate": "结束日期（可选，格式：yyyy-MM-dd）"
}
```

| 参数名               | 类型      | 必填 | 默认值 | 说明                           |
| -------------------- | --------- | ---- | ------ | ------------------------------ |
| `current`            | `long`    | 否   | `1`    | 当前页码（从 1 开始）          |
| `size`               | `long`    | 否   | `10`   | 每页条数                       |
| `id`                 | `String`  | 否   | -      | 项目 ID（精确匹配）            |
| `name`               | `String`  | 否   | -      | 项目名称（模糊匹配）           |
| `deptId`             | `Integer` | 否   | `27`   | 部门 ID                        |
| `projectManagerName` | `String`  | 否   | -      | 项目经理姓名（模糊匹配）       |
| `projectSaleName`    | `String`  | 否   | -      | 项目销售姓名（模糊匹配）       |
| `projectYearMonth`   | `String`  | 否   | -      | 项目年月（格式：`YYYY-MM`）    |
| `startDate`          | `String`  | 否   | -      | 开始日期（格式：`YYYY-MM-DD`） |
| `endDate`            | `String`  | 否   | -      | 结束日期（格式：`YYYY-MM-DD`） |

## **3. 返回结果**

### **响应体 (`IPage<ProjectDTO>`)**

| 字段名             | 类型               | 说明                     |
| ------------------ | ------------------ | ------------------------ |
| `records`          | `List<ProjectDTO>` | 当前页的项目数据列表     |
| `total`            | `long`             | 总记录数                 |
| `size`             | `long`             | 每页条数                 |
| `current`          | `long`             | 当前页码                 |
| `orders`           | `List<OrderItem>`  | 排序字段（未使用则为空） |
| `optimizeCountSql` | `boolean`          | 是否优化 COUNT SQL       |
| `hitCount`         | `boolean`          | 是否命中缓存计数         |
| `searchCount`      | `boolean`          | 是否进行 COUNT 查询      |
| `pages`            | `long`             | 总页数                   |

### **返回示例**

```json
{
  "records": [
    {
      "id": "P1001",
      "name": "测试项目",
      "deptId": 27,
      "projectManagerName": "张三",
      "projectSaleName": "李四",
      "projectYearMonth": "2024-06"
    }
  ],
  "total": 265,
  "size": 10,
  "current": 1,
  "orders": [],
  "optimizeCountSql": true,
  "hitCount": false,
  "searchCount": true,
  "pages": 27
}
```

---

## **4. 注意事项**

1. **分页逻辑**:

   - 如果未传 `current` 或 `size`，默认返回第 1 页的 10 条数据。
   - 页码从 `1` 开始（不是 0）。

2. **模糊查询**:

   - `name`、`projectManagerName`、`projectSaleName` 支持模糊匹配（如 `name: "测试"` 会匹配“测试项目”）。

3. **日期范围**:

   - `startDate` 和 `endDate` 需同时传入才会生效。

4. **默认部门**:
   - 未传 `deptId` 时，默认按 `deptId=27` 过滤。
